## 6. Seed 随机化（`backend/app/seed.py`）

### 6.1 日期锚点

```python
_ANCHOR_2026 = datetime(2026, 1, 1, tzinfo=timezone.utc)
_NOW = datetime.now(timezone.utc)
_D_SINCE = max(1, (_NOW - _ANCHOR_2026).days)

def _ts_2026(max_days_ago=None) -> datetime:
    upper = min(_DAYS_SINCE_2026, max_days_ago) if max_days_ago else _DAYS_SINCE_2026
    return _NOW - timedelta(days=random.randint(0, upper),
                            hours=random.randint(0,23),
                            minutes=random.randint(0,59))
```

所有过去 `_utc(days_ago=N)` / `now - timedelta(days=...)` 调用统一改 `_ts_2026(...)`。

### 6.2 随机配置池

```python
_SEED_CFG = {
    "n_workers": (3, 6),         # 随机 3-6 worker
    "n_tickets": (40, 80),
    "n_cases":   (15, 30),
    "n_guides":  (8, 15),
}
```

工单状态：pending / doing / done / over 按 cfg 比例随机分配（不再写死 5/8/15/2）。

### 6.3 池化标题

扩展 `_TICKET_TITLES` 到 24 条（按 tag 分类），故障参数如温度、振动值 runtime 随机。

案例 / 指导用 10 条高质量模板 + 拼接策略生成到 n_cases/n_guides。

### 6.4 `reset_seed.py`（新文件）

```python
# backend/app/reset_seed.py
from .database import SessionLocal
from .models import User, Device, Ticket, Case, Guide, KnowledgeReport
def reset_and_seed():
    db = SessionLocal()
    try:
        for tbl in [KnowledgeReport, Ticket, Guide, Case, Device, User]:
            db.query(tbl).delete()
        db.commit()
        from .seed import seed_if_empty
        seed_if_empty(db)
    finally: db.close()
```

用法：`python -m backend.app.reset_seed`（生产禁用，仅 demo/测试）。
