一、液压泵类部件故障
##液压系统压力建立不足、压力上不去
## 归属部件：液压泵
### 1.设备简介
液压泵是液压系统动力元件，将机械能转化为液压油压力能，为整个油路提供压力与流量。分为柱塞泵、叶片泵，依靠内部柱塞/叶片周期性容积变化输出压力油。内部磨损、吸油不良、调压机构失效都会直接导致系统压力不足。
### 2.主要结构
泵壳体、柱塞/叶片、配流盘、变量调节机构、吸油口、压油口、骨架油封。
### 3.常见故障
液压系统压力建立不足、压力上不去
### 4.故障原因
1. 液压泵内部柱塞、配流盘磨损，容积效率下降，高压油内部回流；
2. 变量机构卡滞，无法达到最大排量；
3. 吸油管路漏气，油泵吸入空气，有效输出流量降低；
4. 油箱油位过低，吸油供给不足；
5. 溢流阀提前开启泄压（故障区分阀与泵）。
### 5.诊断方法
1. 关闭执行元件油路，单独测泵出口空载压力，区分故障在泵本体还是下游阀组；
2. 监听泵体有无持续气蚀噪声；
3. 查看油箱油位、吸油软管有无老化进气；
4. 调节泵压力调节旋钮，压力无明显变化，判定泵本体故障；
5. 油液取样，观察金属磨屑含量。
### 6.维修流程
1. 设备停机断电，等待液压系统完全泄压；
2. 检查油箱液位，补足合格液压油；检查吸油管路卡箍、密封，消除进气点；
3. 清理吸油滤芯，防止吸油阻力过大；
4. 调压测试依然无法升压，拆卸液压泵；
5. 检修配流盘、柱塞摩擦副，磨损严重直接更换液压泵；
6. 装配完成排净泵体内空气；空载试运行逐步升压；
7. 带载测试系统保压与最高工作压力，记录参数。
### 7.安全规范
1. 必须完全泄压后拆卸高压管路，防止高压油喷射伤人；
2. 废液压油统一回收，禁止随意排放；
3. 压力调试缓慢升压，避免冲击损坏压力表。
### 8.维修案例（真实现场）
故障：液压压机主泵压力只能达到额定压力60%，无法达到工艺压力
现象：调节泵压力旋钮压力提升有限，关闭油缸油路后泵出口压力依旧偏低。
排查：拆解柱塞泵，配流盘磨损出现沟槽，高压油在泵内部回流；吸油软管轻微老化进气。
根因：液压油长期未更换，杂质造成内部摩擦副磨损。
处置：更换柱塞泵总成，更换液压油与吸油滤芯，紧固吸油管路接头；重新排气升压，系统压力恢复额定值。
### 9.关键词
容积效率、配流盘磨损、压力不足、吸油进气、变量机构卡滞、液压柱塞泵


##液压泵异常异响、振动剧烈
## 归属部件：液压泵
### 1.设备简介
液压泵正常运行噪音平稳；当吸入空气、内部部件磨损、吸油阻力过大时，会产生尖锐噪音与剧烈振动。气蚀异响是液压泵典型故障信号，长期持续会快速损毁泵内部精密摩擦副。
### 2.主要结构
泵壳体、柱塞组件、配流盘、吸油滤芯、吸油软管、减震底座。
### 3.常见故障
液压泵异常异响、振动剧烈
### 4.故障原因
1. 吸油管路密封不严，空气进入泵内部产生气蚀爆破噪音；
2. 吸油滤芯堵塞，吸油阻力过高，形成局部负压气蚀；
3. 液压泵内部轴承磨损，旋转部件产生机械撞击噪音；
4. 油箱油位偏低，吸油口露出油面持续吸入空气；
5. 泵底座减震垫老化失效，振动直接传递至机架放大噪音。
### 5.诊断方法
1. 异响随转速升高明显加剧，伴随泵体震动；
2. 打开油箱加油口观察油面，持续出现大量气泡；
3. 触摸吸油管路，管路出现向内吸瘪现象说明滤芯堵塞；
4. 短时关闭吸油侧泄漏点，异响减轻即可判定进气故障；
5. 区分气蚀气泡噪音与内部轴承机械摩擦噪音。
### 6.维修流程
1. 停机断电、系统充分泄压；
2. 检查油箱油位，补充液压油至标准液位；
3. 更换堵塞吸油滤芯，检查吸油软管有无开裂、接头松动；
4. 紧固全部吸油管路卡箍，消除进气通道；
5. 减震垫老化直接更换，隔离振动传递；
6. 整改完成后启动设备，低速运转充分排出油路空气；
7. 逐步提升转速，监听异响是否消除。
### 7.安全规范
1. 气蚀故障不可长期带病运行，极易直接打坏液压泵；
2. 检修管路防止液压油滑落在地面造成人员滑倒；
3. 启动阶段人员避开高压管路冲击方向。
### 8.维修案例（真实现场）
故障：叶片泵运行持续尖锐啸叫异响，泵体剧烈震动
现象：油箱油面不断产生大量泡沫。排查发现吸油软管接头卡箍松动，空气持续吸入系统。
根因：日常巡检忽略吸油低压管路密封，负压条件下持续进气诱发气蚀。
处置：重新紧固吸油管路所有接头，更换老化软管；低速循环排空气，异响与振动完全消除。
### 9.关键词
气蚀、吸油进气、吸油滤芯堵塞、液压泵异响、油液气泡、减震垫失效


##液压泵温升过高
## 归属部件：液压泵
### 1.设备简介
液压泵工作存在正常温升；如果摩擦副磨损、内部持续高压回流、油液粘度不匹配，能量大量转化为热量，造成泵壳体温度超标。高温会加速密封老化、油液氧化变质。
### 2.主要结构
泵内部摩擦副、壳体、泄油口、变量机构、密封组件。
### 3.常见故障
液压泵温升过高
### 4.故障原因
1. 泵内部磨损，高压油持续内泄，液压能转化为热能；
2. 长期高压溢流，大量油液从溢流阀持续泄压发热；
3. 液压油粘度选型错误，粘度过大造成摩擦阻力上升；
4. 油箱容积不足、冷却器堵塞，系统整体散热能力不足；
5. 泄油管路堵塞，泵壳体内部压力升高，加剧摩擦发热。
### 5.诊断方法
1. 红外测温监测泵壳体温度，持续超过70℃属于异常；
2. 空载温度偏低，带负载温度急剧上升，说明内部泄漏；
3. 触摸溢流阀阀体，长期发烫代表持续溢流；
4. 检查泄油管路有无压扁、堵塞，测量泄油流量；
5. 化验液压油粘度，核对是否符合设备要求。
### 6.维修流程
1. 停机泄压，等待设备自然降温；
2. 疏通堵塞泄油管路，保证壳体泄油顺畅回油箱；
3. 检查冷却器，吹扫清理散热通道水垢、油污；
4. 优化工艺，避免长时间高压溢流；
5. 油液粘度不达标更换规定牌号液压油；
6. 持续高温无法缓解，拆解检测泵内部磨损程度，必要时更换液压泵；
7. 试运行持续监测泵体温升曲线。
### 7.安全规范
1. 高温泵体检修谨防烫伤；
2. 高温液压油遇可燃物易起火，及时清理周边油污；
3. 禁止随意封堵泄油管路。
### 8.维修案例（真实现场）
故障：成型机柱塞泵壳体温度长期高于78℃
现象：设备保压阶段溢流阀持续发烫，泵体温升快速上涨。
排查：工艺保压阶段泵持续高压溢流，同时冷却器内部油污堵塞散热变差。
根因：缺少保压节能控制，长时间溢流发热；冷却装置长期未维护。
处置：清理冷却器，优化程序缩短持续保压时长；增加油温巡检点位。整改后泵体温度稳定在55℃区间。
### 9.关键词
泵体温升、内部泄漏、持续溢流、泄油管路堵塞、油液粘度、冷却器堵塞


##液压泵吸空、产生气蚀
## 归属部件：液压泵
### 1.设备简介
液压泵吸油腔必须保持密闭充满油液；一旦空气持续进入或者吸油阻力过大，油液内部形成负压析出气泡，气泡在高压区瞬间爆破形成气蚀，持续冲击金属表面，造成泵内部零件点蚀损伤。
### 2.主要结构
吸油口、吸油管路、吸油滤芯、油箱、油位计。
### 3.常见故障
液压泵吸空、产生气蚀
### 4.故障原因
1. 油箱油位过低，吸油管口暴露在油面上方；
2. 吸油管路接头、法兰密封破损，负压吸入空气；
3. 吸油滤芯严重堵塞，流通面积不足，吸油负压过高；
4. 吸油软管老化软化，运行中被大气压压扁，油路通径缩小；
5. 液压油长期使用，消泡性能失效，气泡无法快速消散。
### 5.诊断方法
1. 泵体出现持续“噼啪”爆破类异响；
2. 油箱油面持续存在大量泡沫，久久无法消散；
3. 系统压力波动、执行元件动作抖动；
4. 拆开吸油管路，观察滤芯堵塞程度；
5. 低速运行异响减轻，高速运行气蚀噪音加剧。
### 6.维修流程
1. 停机泄压，补充液压油至规定油位；
2. 全面检查吸油低压管路，更换老化吸油软管；
3. 更换堵塞吸油滤芯，清理油箱底部沉积杂质；
4. 紧固全部吸油接头密封，加装密封圈消除进气缝隙；
5. 油液消泡性能变差时更换液压油；
6. 启动设备低速循环，充分排出系统积存空气；
7. 逐级提升转速，确认气泡、异响消失。
### 7.安全规范
1. 气蚀会永久性损伤配流盘、柱塞，发现气泡异响立即降载；
2. 禁止拆除吸油滤芯强行运行，杂质会直接磨损液压泵；
3. 更换液压油避免杂质带入油路。
### 8.维修案例（真实现场）
故障：原料输送液压泵持续噼啪气蚀噪音，压力波动大
现象：油箱表层堆积大量白色泡沫。排查发现吸油滤芯完全被粉尘堵塞，吸油阻力过大诱发气蚀。
处置：更换吸油滤芯，清理油箱沉积物；低速排空气。气蚀噪音消除，系统压力恢复平稳。
### 9.关键词
气蚀气泡、吸空、吸油滤芯、油液消泡性、压力波动、负压进气


# #液压泵外泄漏油
## 归属部件：液压泵
### 1.设备简介
液压泵轴伸位置、端盖依靠密封件隔绝压力油；密封老化、轴颈磨损、装配不当会出现外部漏油。持续漏油会造成油箱液位下降，诱发吸空气蚀，油污带来滑倒、火灾隐患。
### 2.主要结构
骨架油封、端盖密封垫、泵壳体法兰、轴颈、泄油口接头。
### 3.常见故障
液压泵外泄漏油
### 4.故障原因
1. 主轴骨架油封长期高温老化，唇口硬化失去密封能力；
2. 轴颈磨损、存在划痕，持续划伤油封唇口；
3. 泵端盖密封垫挤压破损，端盖缝隙渗油；
4. 泄油管路堵塞，泵壳体内压力升高，顶开密封向外渗漏；
5. 油封装配歪斜，唇口无法均匀贴合轴颈。
### 5.诊断方法
1. 目视区分渗漏位置：主轴油封漏油/端盖法兰渗油/泄油接头渗漏；
2. 疏通泄油管路后，渗漏明显减轻判定壳体压力超标；
3. 拆解检查轴颈表面有无沟槽、锈蚀；
4. 观察油封有无硬化、开裂、唇口磨损。
### 6.维修流程
1. 停机断电、系统充分泄压，收集泄漏液压油；
2. 疏通堵塞泄油管路，保证壳体压力正常；
3. 轴伸漏油：拆卸泵联轴器，取出旧油封；轴颈轻微划痕抛光修复；更换全新骨架油封，平整装配；
4. 端盖渗油：拆开端盖，更换密封垫，对角均匀紧固螺栓；
5. 装配完成清理外部油污；空载运行持续观察渗漏情况。
### 7.安全规范
1. 地面泄漏液压油及时擦拭，防止人员滑倒；
2. 高温泵体等待降温再更换油封，防止烫伤；
3. 废油集中回收，禁止随意流淌。
### 8.维修案例（真实现场）
故障：柱塞泵主轴油封持续向外渗漏液压油
现象：泵体下方长期积油，每周需要补充液压油。拆解发现骨架油封老化开裂，同时泄油管路压扁流通不畅，壳体压力偏高加剧渗漏。
处置：更换全新油封，校正疏通泄油管路；试运行无渗漏。
### 9.关键词
骨架油封、轴伸漏油、泄油堵塞、端盖渗油、轴颈划痕、密封老化


二、液压阀类部件故障
# #溢流阀阀芯卡滞，系统压力无法建立
## 归属部件：液压阀（溢流阀）
### 1.设备简介
溢流阀是系统压力控制核心元件，维持系统设定压力，多余油液溢流回油箱。油液杂质卡住阀芯，阀芯无法封闭出油口，压力油持续回流油箱，直接造成系统压力上不去。
### 2.主要结构：阀套、阀芯、调压弹簧、先导控制油路、阻尼孔。
### 3.常见故障
溢流阀阀芯卡滞，系统压力无法建立
### 4.故障原因
1. 液压油含有金属碎屑、粉尘，卡在阀芯与阀套间隙；
2. 阻尼孔堵塞，先导压力无法建立，主阀芯提前开启；
3. 调压弹簧疲劳断裂、刚度不足；
4. 油温过低，油液粘度过大，阀芯运动阻力上升；
5. 阀块内部铸造毛刺脱落，卡住阀芯。
### 5.诊断方法
1. 液压泵出口压力偏低，调节溢流阀调压旋钮压力无变化；
2. 触摸溢流阀回油管路，持续大量油液回流；
3. 拆卸溢流阀，目视阀芯表面存在杂质、划痕；
4. 清洗阀芯装回短时恢复压力，基本判定杂质卡滞。
### 6.维修流程
1. 停机断电，系统完全泄压；
2. 拆下溢流阀总成，拆解主阀芯、先导阀芯；
3. 使用洁净液压油清洗全部零部件，清理阻尼孔杂质；
4. 阀芯出现拉伤划痕无法修复，直接更换溢流阀；
5. 检查调压弹簧，断裂、弹力衰减进行更换；
6. 装配完成，缓慢调节压力，空载、带载逐级升压测试；
7. 同步更换系统液压滤芯，减少再次卡堵风险。
### 7.安全规范
1. 压力调节缓慢操作，防止瞬时高压冲击压力表；
2. 拆卸阀块前确认系统泄压完毕；
3. 禁止使用硬物捅刺阻尼孔，避免孔径变形。
### 8.维修案例（真实现场）
故障：液压剪切机系统压力达不到工作设定值，调节溢流阀无效
现象：溢流阀回油管持续大量回油。拆解发现先导阻尼孔被细小金属碎屑堵塞，主阀芯处于常开状态。
根因：滤芯长期未更换，油液杂质进入阀组。
处置：彻底清洗溢流阀，疏通阻尼孔；更换系统滤芯与液压油。系统压力顺利调整至额定工作压力。
### 9.关键词

# #电磁换向阀卡滞，油缸无法换向动作

### 1.设备简介
电磁换向阀依靠电磁铁推动阀芯移动，切换油路方向，控制油缸伸出、缩回。阀芯被杂质卡阻、电磁铁推力不足时，阀芯无法到位，油路无法切换，执行元件保持不动。
### 2.主要结构：电磁铁、阀芯、阀套、复位弹簧、阀体、电磁铁推杆。
### 3.常见故障
电磁换向阀卡滞，油缸无法换向动作
### 4.故障原因
1. 油液杂质进入阀芯间隙，卡住阀芯无法移动；
2. 电磁铁线圈烧毁、吸力不足，无法推动阀芯；
3. 复位弹簧断裂、弹力不足，阀芯无法复位；
4. 油温过低，油液粘度高，阀芯运动阻力增大；
5. 电磁铁推杆磨损，行程不足无法推到位。
### 5.诊断方法
1. 给出换向指令，电磁铁无吸合声响→电气故障；有响声油缸不动作→阀芯机械卡滞；
2. 断电手动推动电磁铁应急推杆，油缸能够动作，判定阀芯轻微卡滞；
3. 拆解阀体观察阀芯有无划痕、杂质附着；
4. 万用表测量电磁铁线圈通断，区分电气/液压故障。
### 6.维修流程
1. 停机泄压，切断电磁铁供电；
2. 线圈损坏：更换同规格电磁铁；
3. 阀芯卡滞：拆卸阀体，洁净油清洗阀芯与阀套；
4. 阀芯拉伤严重直接更换换向阀；检查复位弹簧完好性；
5. 装配完成通电多次换向测试；
6. 更换系统液压滤芯，降低杂质再次卡堵概率。
### 7.安全规范
1. 测试换向动作注意油缸运动范围，防止撞击周边设备；
2. 电磁铁属于电气元件，清洗阀体避免进水造成短路；
3. 不要长时间持续通电烘烤电磁铁线圈。
### 8.维修案例（真实现场）
故障：升降油缸无法伸出，换向阀电磁铁通电有动作声响，油缸无响应
现象：按下手动应急推杆油缸正常伸出。拆解阀芯发现细小橡胶碎屑卡在阀芯槽内。

处置：清洗换向阀，更换系统滤芯，同步排查更换老化油管密封。换向功能恢复正常。
### 9.关键词

##节流阀调节失效，执行元件速度失控
## 归属部件：液压阀（节流阀/单向节流阀）
### 1.设备简介
节流阀依靠改变节流开口通流面积，调节通过流量，控制油缸运动速度。节流口堵塞、阀芯磨损会造成调节功能失效，油缸速度忽快忽慢或者完全不受调节。

### 3.常见故障
节流阀调节失效，执行元件速度失控
### 4.故障原因
1. 油液杂质卡在节流窗口，通流面积不受手轮调节控制；
2. 节流阀芯长期冲刷磨损，节流边产生缺口，流量不稳定；
3. 单向节流阀单向密封失效，反向无法锁止流量；
4. 调节螺杆螺纹锈蚀，手轮空转，阀芯无法移动；
5. 油温剧烈变化，油液粘度改变，流量随温度漂移。

1. 旋转节流调节手轮，油缸运行速度无明显变化；
2. 速度出现无规律波动，伴随抖动；
3. 拆解观察节流窗口附着杂质、阀芯节流边磨损缺口；
4. 油温升高速度明显加快，判定粘度影响。
### 6.维修流程
1. 停机泄压，拆卸节流阀；
2. 拆解清洗节流阀芯，清除节流窗口杂质；
3. 节流边磨损出现缺口，直接更换节流阀；
4. 锈蚀调节螺杆除锈润滑，严重锈蚀更换；
5. 装配后反复调节手轮，测试快慢速区间；
6. 优化系统油温控制，减小粘度波动影响。
### 7.安全规范
1. 速度失控油缸存在撞击风险，调试速度区域预留安全缓冲；
2. 节流阀清洗禁止使用硬质工具刮擦节流精密棱边；
3. 调节完成锁紧手轮防松螺母，防止运行震动移位。
### 8.维修案例（真实现场）
故障：压紧油缸进给速度调节失灵，旋转手轮速度几乎不变
现象：油缸运行速度持续偏快，调节范围极小。拆解节流阀，节流窗口堆积细小金属粉末。
根因：液压滤芯破损，杂质进入节流阀堵塞节流通道。
处置：清洗节流阀，更换全套液压滤芯；重新调试进给速度，调节功能恢复。
### 9.关键词
节流阀、节流窗口堵塞、流量不稳定、速度失控、阀芯冲刷磨损、单向节流阀


# #阀组内部内泄，油缸自动沉降
## 归属部件：液压阀（换向阀/液控单向阀）
### 1.设备简介
垂直升降油缸依靠阀组封闭油缸上下腔油液实现位置保持。阀芯与阀套密封面磨损，高压油在阀内部互通形成内泄；无外力锁止时，油缸在自重作用缓慢向下沉降，存在安全风险。
### 2.主要结构：换向阀芯、阀套、液控单向阀密封锥面、阀体。
### 3.常见故障
阀组内部内泄，油缸自动沉降
### 4.故障原因
1. 换向阀阀芯、阀套间隙磨损加大，高低压油腔互通；
2. 液控单向阀锥面附着杂质，锥面密封不严持续泄漏；
3. 油液杂质冲刷锥面，产生凹坑，密封失效；
4. 液控单向阀控制油路残余压力，持续顶开密封锥面；
5. 油温升高，油液粘度下降，泄漏量进一步增大。

1. 油缸停止动作断电静置，活塞杆持续缓慢下移；

3. 拆解液控单向阀，观察锥面有无杂质、压痕；

### 6.维修流程
1. 使用机械支撑托举负载，防止油缸沉降伤人；停机泄压；
2. 拆卸阀块，拆解液控单向阀、换向阀；
3. 清洗单向阀密封锥面杂质；锥面出现压痕直接更换阀件；
4. 换向阀间隙磨损严重更换换向阀；
5. 装配完成，空载测试油缸静置保压性能；
6. 增设油缸机械锁紧装置作为双重安全防护。
### 7.安全规范
1. 垂直油缸自动沉降属于高危隐患，检修前必须机械支撑负载；
2. 禁止长期依靠液压锁完全承载重型负载；
3. 维修完成必须长时间静置测试沉降量达标再投入生产。
### 8.维修案例（真实现场）
故障：立式料仓升降油缸停机后缓慢自动下沉
现象：停机半小时活塞杆下沉12cm。封堵油缸油口，沉降停止，判定阀组内泄。拆解液控单向阀，锥面卡住细小硬质颗粒，密封无法闭合。
处置：清洗阀块与单向阀，更换液压滤芯；测试静置2小时沉降量＜2mm，满足工艺要求。
### 9.关键词
阀组内泄、油缸自重沉降、液控单向阀、锥面密封、保压失效、液压锁

4. 接头螺纹均匀涂抹少量螺纹润滑脂，禁止大力猛拧；
5. 按照标准力矩紧固管接头；
6. 空载逐步升压，持续观察接头有无再次渗漏。

1. 高压渗漏油极易喷射伤人，禁止带压强行拧紧接头；
2. 泄漏油污及时清理，防滑、防火；
3. 密封圈规格严格匹配，禁止不同尺寸临时替代。
### 8.维修案例（真实现场）
故障：换向阀块油管接头持续渗油
现象：设备压力上升渗漏加重。拆卸发现O圈长期受热硬化，安装时局部被螺纹剪切出缺口。

# #液压缸动作缓慢、运动爬行
## 归属部件：液压缸
### 1.设备简介
液压缸将液压压力能转化为直线机械推力，推动负载往复运动。系统进气、密封摩擦阻力不均、流量不足时，活塞杆出现一顿一顿爬行现象，进给速度达不到工艺要求。
### 2.主要结构：缸筒、活塞、活塞杆、活塞密封、导向带、端盖、缓冲机构。
### 3.常见故障
液压缸动作缓慢、运动爬行
### 4.故障原因
1. 系统油路混入大量空气，油液可压缩造成断续出力；
2. 活塞密封摩擦力不均匀，静摩擦大于动摩擦引发爬行；
3. 供油流量不足，滤油器堵塞、泵排量下降；
4. 活塞杆与缸筒不同心，侧向力增大摩擦阻力；
5. 负载导轨润滑不良，机械阻力持续波动。

1. 低速运行油缸一顿一顿移动，提高速度爬行现象减轻；
2. 松开油缸排气螺钉持续排出气泡，判定系统进气；
3. 单独测试供油流量，区分是流量不足还是油缸本体摩擦问题；
4. 手动推动负载，检查外部导轨阻力是否过大。
### 6.维修流程
1. 打开油缸两端排气阀，低速循环充分排出系统空气；
2. 排查消除管路进气点，修复吸油侧密封；
3. 清理堵塞滤油器，保证供油流量；
4. 校正油缸安装同轴度，减小活塞杆侧向偏载；
5. 给外部负载导轨加注润滑脂，降低机械摩擦；
6. 上述处理依旧爬行，拆解液压缸更换磨损导向带、活塞密封；
7. 空载、带载多次测试运行平顺性。
### 7.安全规范
1. 爬行工况油缸进给不稳定，涉及冲压、压紧工艺做好防护挡板；
2. 拆解重型液压缸使用起重工装，防止活塞杆滑落；
3. 排气操作避免高压油喷出伤人。
### 8.维修案例（真实现场）
故障：进料油缸低速进给持续爬行，动作断断续续
现象：油缸高点排气持续涌出气泡。排查吸油管路接头密封老化进气。
处置：更换吸油管路密封圈，多点彻底排气；校正油缸安装同轴度。爬行现象消除，进给平稳。

油缸爬行、低速抖动、系统进气、导向带磨损、同轴度偏差、流量不足

### 4.故障原因
1. 活塞杆油封长期高温老化，唇口失去弹性；
2. 活塞杆表面出现划痕、锈蚀，持续切割油封唇口；
3. 防尘圈损坏，粉尘杂质进入，研磨油封与活塞杆；
4. 油缸侧向受力，活塞杆单边挤压油封；
5. 油封装配时唇口翻转、划伤。
### 5.诊断方法
1. 活塞杆伸缩过程表面附着油膜，油缸下端持续积油；
2. 擦拭干净活塞杆，往复运动一段时间再次出现油迹；
3. 目视活塞杆表面有无磕碰划痕、锈蚀斑点。
### 6.维修流程
1. 机械支撑负载，停机泄压；
2. 拆解油缸前端端盖，取出防尘圈、活塞杆油封；
3. 抛光修复活塞杆轻微划痕；锈蚀严重更换活塞杆；
4. 更换全新成套防尘圈、主油封，装配注意油封唇口朝向油腔一侧；
5. 校正油缸安装同轴度，消除侧向偏载；
6. 洁净装配，避免杂质带入密封区域；
7. 往复多次伸缩油缸，持续观察活塞杆渗漏情况。
### 7.安全规范
1. 渗漏油污及时清理，防止人员滑倒；
2. 装配油封禁止尖锐工具划伤唇口；
3. 户外工况重点保护防尘圈，阻挡粉尘泥沙侵入。
### 8.维修案例（真实现场）
故障：升降油缸活塞杆持续渗油，地面长期积油
现象：防尘圈破损，金属粉尘进入端盖内部，划伤活塞杆与油封。
处置：抛光修复活塞杆划痕，更换防尘圈与主油封，校正油缸安装支架。试运行活塞杆无油膜渗出。
### 9.关键词
活塞杆漏油、杆封油封、防尘圈损坏、活塞杆划伤、侧向载荷、密封唇口


# #液压缸运动卡顿、局部卡死
## 归属部件：液压缸
### 1.设备简介
理想液压缸全程运动阻力均匀；缸筒变形、导向带磨损、活塞杆不同心，会在行程某一位置阻力急剧增大，出现卡顿、推不动现象。
### 2.主要结构：缸筒、活塞、导向带、活塞杆、端盖支撑。
### 3.常见故障
液压缸运动卡顿、局部卡死
### 4.故障原因
1. 油缸安装不同心，活塞杆运行侧向挤压导向带；
2. 导向带磨损粉末堆积，局部摩擦力急剧上升；
3. 缸筒内壁局部锈蚀、磕碰变形，内径缩小；
4. 活塞密封膨胀卡滞，高温工况更加明显；
5. 外部负载导轨异物卡阻，传递至油缸。
### 5.诊断方法
1. 油缸运行到固定行程位置阻力变大，出现停顿卡顿；其余位置运行顺畅；
2. 断开油缸与负载连接，单独空载伸缩油缸，区分机械负载故障还是油缸本体故障；
3. 拆解观察导向带磨损、缸筒内壁变形锈蚀情况。
### 6.维修流程
1. 停机泄压，分离油缸与外部负载；
2. 空载测试油缸，卡顿依旧存在说明油缸本体故障；
3. 拆解液压缸，清理内部杂质；更换磨损导向带、密封件；
4. 缸筒变形严重则更换缸筒；
5. 重新校正油缸安装同轴度，消除侧向力；
6. 装配完成空载全程往复测试，确认无卡点；
7. 连接负载再次全程试运行。
### 7.安全规范
1. 强行加压通过卡顿位置极易损坏密封与缸筒；
2. 重型油缸拆解使用起重工装，防止构件坠落；
3. 排查外部负载异物，避免修好油缸再次被负载损伤。
### 8.维修案例（真实现场）
故障：推送油缸运行至行程中点出现明显卡顿，需要加大压力才能通过
现象：脱开负载空载油缸依旧卡顿。拆解发现导向带磨损碎屑堆积，同时油缸安装偏移产生侧向力。
处置：更换导向带与密封组件，校正油缸安装支架。全程伸缩顺畅，无卡顿现象。
### 9.关键词
油缸卡顿、导向带磨损、安装不同心、缸筒变形、行程卡点、侧向载荷


# #液压缸缓冲失效，终端撞击
## 归属部件：液压缸
### 1.设备简介
液压缸两端内置缓冲机构，活塞到达行程末端节流减速，防止金属刚性撞击。缓冲节流槽堵塞、缓冲密封损坏，减速功能失效，活塞高速撞击端盖，产生巨大冲击噪音，长期冲击损坏缸体、负载设备。
### 2.主要结构：缓冲柱塞、缓冲节流槽、缓冲密封圈、端盖。
### 3.常见故障
液压缸缓冲失效，终端撞击
### 4.故障原因
1. 缓冲节流槽被油液杂质堵塞，无法形成节流减速；
2. 缓冲密封圈磨损，高压油短路绕过缓冲区域；
3. 缓冲柱塞磕碰变形，无法进入缓冲腔；
4. 负载惯性过大，超出缓冲设计能力；
5. 系统流量过大，油缸运行速度过快。
### 5.诊断方法
1. 油缸到达行程终点出现巨大金属撞击声响；
2. 调节系统流量降低速度，撞击减轻；
3. 拆解观察缓冲节流槽有无杂质堵塞、柱塞变形。
### 6.维修流程
1. 停机泄压，拆解油缸端盖缓冲机构；
2. 清理节流槽内部堵塞杂质；
3. 缓冲密封圈磨损、柱塞变形，更换相关零件；
4. 适当降低供油流量，减小油缸运行速度；
5. 惯性超大负载，额外增设外部液压缓冲器；
6. 装配完成，往复运行测试终端减速缓冲效果。
### 7.安全规范
1. 终端刚性撞击长期运行会造成缸筒焊缝、底座开裂；
2. 撞击区域设置防护挡板，防止工件弹跳飞出；
3. 不要依靠加大缓冲压力强行抵消超大惯性负载。
### 8.维修案例（真实现场）
故障：下料油缸缩回终点剧烈撞击，噪音巨大
现象：缓冲节流槽堆积细小杂质，节流通道堵塞，失去减速功能。
处置：拆解清理缓冲槽杂质，更换缓冲密封；适当降低换向阀供油流量。终端撞击噪音显著减弱。
### 9.关键词
油缸缓冲失效、终端撞击、缓冲节流槽、缓冲柱塞、惯性负载、末端减速
