一、三相异步电机类故障
## 电机无法启动
## 归属部件：三相异步电机
### 1.设备简介
三相异步电机将电能转换为旋转机械能，作为各类机械设备动力源，依靠定子旋转磁场驱动转子运转，广泛应用泵、风机、输送设备。供电条件、绕组状态、控制回路、机械负载卡滞均会直接影响电机启动性能。
### 2.主要结构
定子绕组、转子、前后端轴承、电机接线盒、冷却风扇、端盖；配套外部接触器、热继电器、动力电缆。
### 3.常见故障
电机无法启动
### 4.故障原因
1. 供电电源故障：三相电源缺相、无电压、电压过低；
2. 控制回路故障：启停按钮损坏、接触器线圈断路、热继电器保护跳闸未复位；
3. 电机本体故障：定子绕组断路、接线盒端子松动烧蚀；
4. 机械卡滞：负载卡死、电机轴承抱死，阻力过大无法转动；
5. 保护元件动作：过载保护、急停回路断开，控制回路失电。
### 5.诊断方法
1. 按下启动按钮，观察接触器是否正常吸合；无吸合优先排查控制回路；
2. 接触器吸合：使用万用表测量电机接线盒三相电压，判断动力供电是否正常；
3. 断电后测量电机三相绕组通断，排查绕组断路；
4. 断开联轴器，单独盘动电机转子，区分电气故障还是机械负载卡死；
5. 检查热继电器、急停安全回路是否处于保护断开状态。
### 6.维修流程
1. 执行断电、验电、上锁挂牌LOTO作业；
2. 接触器不吸合：逐段排查按钮、线圈、安全联锁线路，修复断线、更换损坏元器件；
3. 接触器吸合但电机不转：检测接线端子，紧固烧蚀松动端子；绕组断路需拆机维修电机；
4. 判定负载机械卡死：解除电机与负载连接，单独检修机械设备；
5. 故障消除后，先空载点动电机，观察运转状态；
6. 空载运行无异常，再接上负载试运行，记录启动电流。
### 7.安全规范
1. 电气检修必须断电验电，禁止带电拆开电机接线盒；
2. 多次启动失败不要反复强行合闸，防止烧毁电机绕组；
3. 断开联轴器盘车时防止转轴突然转动夹伤；
4. 检修完成确认所有防护罩复位。
### 8.维修案例（真实现场）
故障：输送皮带电机按下启动按钮无法运转
现象：启动指令发出，控制柜接触器正常吸合，但电机完全不转动，无任何声响。
排查：接线盒内一相接线端子长期发热氧化断开；三相供电缺少一相，电机无法建立旋转磁场。
根因：端子压接不实，运行发热，导线逐步烧断。
处置：清理接线盒氧化层，重新压接电缆端子，紧固螺栓；增加端子温度巡检项目。修复后电机启停正常。
### 9.关键词
电机启动失败、端子烧蚀、缺相、接触器、控制回路、负载卡滞


## 电机缺相过热运行
## 归属部件：三相异步电机
### 1.设备简介
三相异步电机依靠三相平衡交流电产生旋转磁场。当三相电源缺失一相时，磁场畸变，电机转矩大幅下降，运行电流急剧上升，短时间内造成绕组烧毁，是现场高发严重电气故障。
### 2.主要结构
定子三相绕组、转子、接线端子、冷却风扇；上游供电电缆、接触器主触点、断路器。
### 3.常见故障
电机缺相过热运行
### 4.故障原因
1. 接触器某一相主触点电弧烧蚀、接触不良，形成虚断；
2. 动力电缆内部单芯导线断裂、接线端子松动；
3. 上游断路器一相脱扣、熔断器单相熔断；
4. 接线盒内导线震动松脱，单相供电中断。
### 5.诊断方法
1. 电机运行异响、转速下降，机身温度快速升高；
2. 使用钳形电流表测量三相电流，出现两相电流大幅偏高，一相无电流；
3. 停机断电后分段测量三相回路通断，定位断线、触点不良位置；
4. 对比三相绕组阻值，初步区分断线点位在电机内部还是外部线路。
### 6.维修流程
1. 发现异常立刻停机断电，禁止继续带病运行；执行上锁挂牌；
2. 分段测量电压、通断，确定缺相故障点（断路器/接触器/电缆/电机端子）；
3. 触点烧蚀：更换接触器；电缆断线重新制作电缆接头或更换线缆；
4. 电机长时间缺相运行后，使用兆欧表测量绕组绝缘，绝缘破损必须大修电机；
5. 全面紧固全部动力接线端子；
6. 上电空载试运行，持续监测三相电流平衡性；带载复测电流。
### 7.安全规范
1. 缺相运行极易烧毁电机，巡检发现异响、升温异常第一时间停机；
2. 带电测量电压做好绝缘防护；
3. 禁止拆除热继电器、缺相保护装置强行运行。
### 8.维修案例（真实现场）
故障：循环水泵电机缺相运行，机身高温报警
现象：电机运行嗡嗡异响，出力不足，外壳温度快速升高。钳表检测A相无电流。
排查：接触器A相主触点电弧烧蚀，无法导通。
根因：接触器长期启停，触点氧化熔损，形成单相虚断。
处置：更换全新交流接触器，紧固所有动力端子；增设电机三相电流日常巡检。设备运行三相电流平衡，温升正常。
### 9.关键词
电机缺相、触点烧蚀、三相电流不平衡、绕组过热、单相断路


## 电机绕组绝缘降低、接地短路
## 归属部件：三相异步电机
### 1.设备简介
电机定子绕组外层绝缘漆隔离导体与机壳，防止漏电。在受潮、高温、粉尘、老化作用下绝缘层破损，绕组导体接触机壳，引发漏电、跳闸，严重时直接击穿烧毁绕组。
### 2.主要结构
定子绕组、绝缘漆膜、接线盒、电机机壳、轴承；配套接地保护线路。
### 3.常见故障
电机绕组绝缘降低、接地短路
### 4.故障原因
1. 电机长期停机受潮，水汽渗入绕组，绝缘电阻下降；
2. 电机持续超温运行，绝缘漆老化、碳化；
3. 粉尘、油污进入定子腔体，形成导电通道；
4. 转子扫膛摩擦定子，刮伤绕组绝缘；
5. 电缆进水，水分顺着接线盒侵入绕组。
### 5.诊断方法
1. 合闸启动立刻触发漏电保护器、断路器跳闸；
2. 断电断开外部电缆，使用500V兆欧表测量绕组对地绝缘电阻；
3. 绝缘数值低于0.5MΩ判定绝缘不良；阻值接近0Ω说明绕组直接接地；
4. 分别测量三相绕组对地阻值，定位故障相。
### 6.维修流程
1. 断电上锁挂牌，拆开电机接线盒，断开外部动力电缆；
2. 区分故障位置：外部电缆接地 或 电机本体绕组接地；
3. 绕组轻度受潮：拆除电机端盖，采用热风烘干绕组，复测绝缘；
4. 绝缘击穿、绕组对地短路：电机需要返厂重新浸漆大修；
5. 排查进水进尘源头，修复接线盒密封；
6. 修复完成后再次测量绝缘，达标后方可上电试运行。
### 7.安全规范
1. 兆欧表测试过程禁止人员触碰绕组端子，防止感应电击；
2. 绝缘不合格电机严禁投入运行，存在外壳触电风险；
3. 检修完成确认电机保护地线可靠连接。
### 8.维修案例（真实现场）
故障：室外排水电机一启动漏电开关立即跳闸
现象：无法启动，一合闸保护动作。断开电缆单独测量电机，C相对地绝缘电阻趋近于0。
排查：雨季电机接线盒密封老化进水，水分渗入定子绕组，造成绕组接地。
根因：接线盒密封圈老化缺失，雨水灌入电机内部。
处置：拆解电机烘干绕组，更换接线盒密封件；复测绝缘达标后投运；雨季增加电机绝缘定期检测。
### 9.关键词
绕组接地、绝缘电阻、兆欧表、电机受潮、绝缘老化、漏电跳闸


# #电机运行三相电流不平衡
## 归属部件：三相异步电机
### 1.设备简介
正常三相异步电机三相运行电流差值不超过额定电流10%。电流不平衡会产生负序磁场，增大电机损耗、振动与温升，长期运行加速绕组老化，诱发缺相、短路故障。
### 2.主要结构
定子三相绕组、接线端子、动力电缆、接触器触点、空气开关。
### 3.常见故障
电机运行三相电流不平衡
### 4.故障原因
1. 外部线路问题：某一相接线端子松动、接触电阻偏大；
2. 接触器个别触点接触不良，单相压降大；
3. 电机内部绕组匝间轻微短路；
4. 三相供电电网电压本身不平衡；
5. 电缆三相长度不一致、敷设间距差异，阻抗不平衡。
### 5.诊断方法
1. 钳形电流表采集三相工作电流，计算电流差值；
2. 空载状态测量电机接线盒三相电压，判断供电电压平衡度；
3. 断电测量三相绕组直流电阻，阻值偏差过大代表绕组异常；
4. 紧固全部端子后再次复测电流，区分接触不良故障。
### 6.维修流程
1. 电机带载运行采集三相电流数据；停机断电上锁；
2. 全面紧固接线盒、控制柜内所有动力接线端子；
3. 检测接触器触点有无烧蚀，触点损坏直接更换；
4. 测量三相绕组直流电阻，偏差超标说明电机匝间故障，安排电机检修；
5. 核对上游三相供电电压，联系配电班组处理电网不平衡问题；
6. 整改完成上电，空载、带载两次复测三相电流。
### 7.安全规范
1. 钳形表带电测量保持绝缘距离，防止相间短路；
2. 电流不平衡超标设备不能长期持续运行；
3. 排查过程不要短接各类保护装置。
### 8.维修案例（真实现场）
故障：风机电机三相电流偏差达到18%，电机温升偏高
现象：B相电流明显高于A、C两相。紧固所有端子后效果有限。
排查：接触器B相触点轻微烧蚀，接触电阻增大，单相压降偏高。
根因：接触器长期频繁启停，触点局部氧化。
处置：更换交流接触器，再次紧固所有接线端子。整改后三相电流差值降至6%以内，电机温升恢复正常。
### 9.关键词
三相电流不平衡、绕组直流电阻、触点接触不良、匝间短路、负序磁场


## 电机轴承电磁异响、扫膛
## 归属部件：三相异步电机
### 1.设备简介
电机定转子之间存在均匀微小气隙，气隙不均会产生单边磁拉力，引发电磁噪音；轴承磨损、端盖移位造成转子摩擦定子铁芯，该现象称为扫膛，严重直接刮坏绕组绝缘。故障兼具机械与电气双重特征。
### 2.主要结构
定子铁芯、转子、前后支撑轴承、电机端盖、轴承压盖。
### 3.常见故障
电机轴承电磁异响、扫膛
### 4.故障原因
1. 轴承磨损游隙变大，转子径向晃动，定转子气隙不均匀；
2. 电机端盖螺栓松动，端盖偏移，转子偏心；
3. 转轴弯曲变形，转子旋转摆动；
4. 装配轴承时预紧间隙调整不当；
5. 基础振动导致电机长期偏心运行。
### 5.诊断方法
1. 通电运行存在持续低频电磁嗡嗡异响；断电依靠惯性空转时噪音明显减小；
2. 严重扫膛运行伴随周期性摩擦声响；停机盘车存在局部摩擦卡点；
3. 听音棒区分纯机械轴承噪音和电磁异响；
4. 拆解测量定转子四周气隙，气隙差值超过标准判定偏心。
### 6.维修流程
1. 停机断电上锁挂牌；断开联轴器；
2. 松开电机端盖螺栓，重新均匀对角紧固，校正端盖位置；
3. 轴承磨损、转子晃动：拆解更换电机轴承；
4. 转轴弯曲：校正或者更换电机主轴；
5. 清理定转子摩擦产生的金属碎屑，检查定子绕组有无刮伤；
6. 装配完成手动盘车，无摩擦卡点；空载通电试运行监听噪音。
### 7.安全规范
1. 扫膛故障持续运行极易磨破绕组，发现摩擦声响及时停机；
2. 拆解电机吊装做好防护，防止磕碰定子绕组；
3. 试车前确认电机接地线完好。
### 8.维修案例（真实现场）
故障：引风机电机通电出现持续电磁嗡鸣异响
现象：通电异响明显，断电滑行阶段噪音显著降低；停机盘车轻微卡点。
排查：电机驱动端轴承磨损，转子偏心，局部定转子气隙过小，出现轻微扫膛。
根因：润滑保养缺失，轴承逐步磨损，转子径向位移。
处置：更换电机两端轴承，重新校正端盖，清理铁芯金属粉末。试运行电磁异响消除。
### 9.关键词
电磁异响、电机扫膛、定转子气隙、转子偏心、单边磁拉力




二、电路线缆类部件故障
## 电缆绝缘破损对地漏电
## 归属部件：电路线缆
### 1.设备简介
动力电缆与控制线缆负责传输电能、传递开关量/模拟量信号。外层绝缘护套、内部绝缘层防止导体对地、相间导通；机械摩擦、挤压、老化、腐蚀都会破坏绝缘层，引发漏电、跳闸安全隐患。
### 2.主要结构
铜导体、内绝缘层、屏蔽层（控制线）、外护套、电缆终端接头、穿线管。
### 3.常见故障
电缆绝缘破损对地漏电
### 4.故障原因
1. 电缆长期与机架、金属棱角摩擦，外护套磨损；
2. 敷设时线缆过度弯折、挤压，内部绝缘开裂；
3. 地沟积水、化学品腐蚀，加速护套老化破损；
4. 高温环境长期烘烤，绝缘材质脆化开裂。
### 5.诊断方法
1. 送电后漏电保护器频繁跳闸，无明显短路冲击；
2. 断开电缆两端所有负载，使用兆欧表测量芯线对地绝缘；
3. 分段解开电缆中间接头，缩小故障范围，定位破损区段；
4. 目视检查电缆桥架、转角位置有无外皮破损痕迹。
### 6.维修流程
1. 全线断电、验电、上锁挂牌；
2. 通过分段绝缘测试，锁定破损线缆区段；
3. 破损位置较短：截除破损段，制作中间电缆接头；
4. 多处破损、线缆老化严重：直接更换整段电缆；
5. 线缆易摩擦位置加装橡胶防护套管，避免再次磨损；
6. 修复完成复测绝缘电阻达标，方可恢复送电；
7. 上电空载测试，确认不再漏电跳闸。
### 7.安全规范
1. 漏电电缆存在触电风险，禁止带病运行；
2. 地沟内作业注意积水防滑，做好绝缘防护；
3. 兆欧表测试时禁止人员触碰导体。
### 8.维修案例（真实现场）
故障：输送机动力电缆间歇性漏电跳闸
现象：设备振动大时频繁触发漏电保护，静置状态可以正常合闸。

处置：切除破损电缆段，制作中间接头，转角加装防护橡胶护套；定期巡检桥架线缆磨损情况。故障消除。

##线缆内部芯线断路、虚接
## 归属部件：电路线缆
### 1.设备简介
线缆导体依靠铜芯持续传输电流，线缆频繁弯折、震动拉扯会造成铜芯疲劳断裂；断裂位置未完全分离形成虚接，表现为时通时断，负载运行发热，是隐蔽性极强电气故障。
### 2.主要结构
铜芯导体、绝缘层、电缆终端压接端子、线槽、拖链。
### 3.常见故障
线缆内部芯线断路、虚接
### 4.故障原因
1. 线缆长期跟随设备往复运动反复弯折（拖链内线缆）；
2. 端子压接不紧实，运行发热氧化，导线逐步断开；
3. 施工时线缆过度拉扯，铜芯内部受损；
4. 振动环境导线疲劳断裂，断点间歇性接触形成虚接。
### 5.诊断方法
1. 设备故障时有时无，晃动电缆故障状态同步变化；
2. 断电使用万用表通断档测量，轻微晃动线缆，通断信号间断出现；
3. 通电测量端子两端电压，虚接点会出现明显电压降；
4. 逐步移动线缆，定位故障大致区间。
### 6.维修流程
1. 断电上锁挂牌；
2. 晃动线缆配合通断测试，锁定故障区段；
3. 断点靠近端头：重新剥线压接冷压端子；
4. 断点在线缆中段：制作中间接头或者更换线缆；
5. 拖链内线缆预留足够弯曲余量，避免硬拉扯；
6. 所有端子按照规范力矩压接，禁止虚压；
7. 修复完成反复晃动线缆测试，确认导通稳定。
### 7.安全规范
1. 虚接位置极易发热起火，发现时通时断故障及时停机；
2. 禁止简单缠绕导线代替正规冷压接头；
3. 移动设备拖链线缆定期检查老化疲劳情况。
### 8.维修案例（真实现场）
故障：升降平台限位控制线时好时坏
现象：偶尔触发限位停机，晃动设备拖链电缆故障反复出现。
排查：拖链内部控制线长期往复弯折，一根芯线铜芯疲劳半断，形成虚接。
根因：线缆敷设余量不足，往复运动持续弯折。
处置：更换拖链专用耐弯折电缆，调整拖链走线预留弯曲余量；故障不再复发。
### 9.关键词
芯线虚接、线缆疲劳断裂、拖链电缆、时通时断、端子压接、电压降



# #控制线干扰，信号乱跳
## 归属部件：电路线缆
### 1.设备简介
4-20mA模拟量、传感器开关信号依靠控制线缆传输。动力电缆大电流产生交变电磁场，若控制线布线、接地不规范，电磁干扰会叠加在信号上，造成PLC信号漂移、数值频繁跳动，引发设备误动作。
### 2.主要结构
屏蔽控制电缆、信号端子、屏蔽层接地线、线槽、动力电缆。
### 3.常见故障
控制线干扰，信号乱跳
### 4.故障原因
1. 控制信号线与动力电缆近距离平行长距离敷设；
2. 屏蔽电缆屏蔽层两端接地、或者完全不接地；
3. 接地桩电位不等，形成地环流引入干扰；
4. 线缆接头屏蔽层断裂，屏蔽连续性破坏。
### 5.诊断方法
1. 动力设备启动瞬间，信号数值剧烈波动；动力停机信号恢复平稳；
2. 示波器或PLC在线监控，信号叠加高频杂波；
3. 临时更换短距离屏蔽线测试，信号恢复正常，确认线缆干扰；
4. 检查屏蔽层接地方式、线缆敷设间距。
### 6.维修流程
1. 优化布线：控制线与动力电缆分隔桥架，保持30cm以上安全间距；
2. 屏蔽线缆执行**单端接地**规范，禁止两端同时接地；
3. 修复断裂的屏蔽层，保证屏蔽连续；
4. 模拟量信号前端加装信号隔离模块；
5. 减少控制线不必要的长线平行敷设；
6. 整改后持续在线监控信号波动情况。
### 7.安全规范
1. 信号紊乱极易造成设备误动作，涉及安全联锁回路优先停机整改；
2. 屏蔽层地线禁止串联接入保护地线主干；
3. 不要随意拆除线缆屏蔽层。
### 8.维修案例（真实现场）
故障：压力变送器4-20mA信号无规律跳动，联锁频繁误触发
现象：大功率泵启动时，压力数值漂移±0.2MPa。
排查：传感器屏蔽控制线和电机动力电缆同槽并行敷设超过60米，屏蔽层两端接地产生地环路干扰。
根因：布线不满足强弱电分离规范，接地方式错误。
处置：控制线单独分隔桥架，屏蔽层只在控制柜一端单点接地，加装信号隔离器。信号波动消除。
### 9.关键词
电磁干扰、屏蔽电缆、单点接地、强弱电分离、4-20mA信号、信号隔离


# #多芯电缆芯间短路
## 归属部件：电路线缆
### 1.设备简介
多芯控制电缆内部有多根独立绝缘芯线。芯线绝缘破损后两根导体互相接触形成芯间短路，造成开关信号误触发、模块通道烧毁，是自控系统常见故障。
### 2.主要结构
多芯铜芯、芯线绝缘、总护套、电缆端子、接线端子排。
### 3.常见故障
多芯电缆芯间短路
### 4.故障原因
1. 电缆端头剥线过长，芯线裸露距离大，相互触碰；
2. 线缆受热老化，内部芯线绝缘融化粘连；
3. 穿线管内线缆受挤压，芯线绝缘破损；
4. 接线端子积灰受潮，形成导电桥，芯线之间间接导通。
### 5.诊断方法
1. PLC模块通道故障报警、输出误动作；
2. 电缆两端全部断开负载，万用表测量不同芯线之间导通；
3. 分段解开电缆接头，逐步缩小短路故障范围；
4. 检查端子排有无凝露、积灰爬电痕迹。
### 6.维修流程
1. 全线断电上锁挂牌；
2. 分段测试锁定短路区段；
3. 故障靠近端头：重新规范剥线、整理芯线，增加绝缘套管隔离；
4. 线缆中段多处芯线短路：直接更换电缆；
5. 清理端子排粉尘、冷凝积水，保持接线区域干燥；
6. 修复完成复测芯线之间绝缘，确认无短路；上电测试信号。
### 7.安全规范
1. 芯间短路可能烧毁PLC、继电器模块，发现通道异常及时断电；
2. 潮湿电控柜加装除湿装置，防止端子爬电短路；
3. 电缆剥线禁止过度切割内部芯线绝缘。
### 8.维修案例（真实现场）
故障：设备两个限位信号互相干扰，同时触发
现象：两个开关量信号异常同时接通。断电测量两根信号线相互导通。
排查：电缆终端剥线过长，裸露芯线紧贴在一起，振动时间歇性接触短路。
根因：前期施工剥线工艺不规范。
处置：重新整理电缆端头，缩短剥线长度，各芯线增加绝缘套管隔离。故障彻底消除。
### 9.关键词
芯间短路、多芯控制电缆、剥线工艺、端子爬电、PLC通道故障


# #电缆接头发热氧化
## 归属部件：电路线缆
### 1.设备简介
电缆接头、端子是线缆能量传输薄弱点。压接不实、螺栓松动会增大接触电阻，负载电流通过时持续发热，逐步氧化，恶性循环，严重时烧断导线、引发起火。
### 2.主要结构
电缆铜鼻子、接线端子、紧固螺栓、平垫弹垫、端子排。
### 3.常见故障
电缆接头发热氧化
### 4.故障原因
1. 接线螺栓紧固力矩不足，长期振动松脱；
2. 铜鼻子压接松散，导线与端子接触面积不足；
3. 铜铝直接接触，产生电化腐蚀，接触电阻上升；
4. 环境潮湿，端子表面氧化生成绝缘氧化层。
### 5.诊断方法
1. 红外测温仪巡检发现端子温度明显高于线缆本体；
2. 断电拆开可见端子发黑、铜导体出现绿色铜锈；
3. 负载增大时发热情况明显加剧；
4. 严重时出现线缆绝缘烤焦气味。
### 6.维修流程
1. 停机断电上锁挂牌，等待接头充分降温；
2. 拆除氧化端子，清理导线铜芯表面氧化层；
3. 铜铝连接必须使用铜铝过渡端子；
4. 使用液压钳规范压接铜鼻子，按照标准力矩对角紧固螺栓；
5. 潮湿环境端子涂抹导电抗氧化膏；
6. 上电带载运行，红外复测接头温度。
### 7.安全规范
1. 端子持续发热属于火灾隐患，严禁长期运行；
2. 禁止不使用弹垫、平垫直接紧固端子；
3. 红外测温定期纳入日常巡检。
### 8.维修案例（真实现场）
故障：水泵控制柜动力端子发热，绝缘外皮烤变色
现象：红外测温端子温度达到76℃，铜鼻子表面发黑氧化。
排查：螺栓未按力矩紧固，长期振动松脱，接触电阻持续增大。
根因：检修后凭手感紧固，没有使用力矩扳手。
处置：打磨清理氧化层，重新压接铜鼻子，力矩扳手规范紧固；建立关键端子红外测温巡检制度。运行温度恢复正常。
### 9.关键词
端子发热、铜鼻子氧化、接触电阻、力矩紧固、铜铝过渡、红外测温

# #控制柜内积灰受潮引发短路
## 归属部件：控制柜
### 1.设备简介
电气控制柜集成断路器、接触器、PLC、电源模块，为整套设备提供配电与逻辑控制。柜体防尘、防潮性能直接决定元器件寿命；粉尘混合水汽会在元器件表面形成导电通路，造成相间、对地短路。

柜体外壳、通风滤网、柜内元器件、母线排、电缆进出线密封接头、柜内加热器。

控制柜内积灰受潮引发短路

1. 通风滤网长期堵塞破损，粉尘大量进入柜体；
2. 早晚温差大，柜内产生凝露，水汽凝结在电路板、母线表面；
3. 电缆进线孔密封失效，水汽、粉尘从缝隙进入；
4. 柜内除湿加热器损坏，无法消除凝露。

1. 潮湿天气更容易出现跳闸、模块损坏故障；
2. 打开柜门目视母线、电路板表面存在灰尘、水珠；

3. 清理凝露水渍，检查元器件有无腐蚀烧损；
4. 更换破损通风防尘滤网，封堵电缆进线多余孔洞；
5. 检修或者更换除湿加热器，设定合理启控温度；
6. 修复受损元器件；关闭柜门试运行，持续观察湿度变化。
### 7.安全规范
1. 吹扫粉尘前务必断电，压缩空气禁止直吹带电电路板；
2. 潮湿柜内严禁带电开展检修；
3. 定期清理滤网，杜绝长期敞开柜门运行。
### 8.维修案例（真实现场）
故障：搅拌设备控制柜梅雨季频繁短路跳闸
现象：清晨极易跳闸，柜内母线表面可见一层薄水珠混合粉尘。

根因：缺少定期柜体防潮维护。
处置：封堵电缆进线缝隙，更换加热器，每周吹扫一次滤网；雨季增加巡检频次。短路故障不再发生。
### 9.关键词
柜内凝露、粉尘短路、除湿加热器、防尘滤网、电缆密封、相间爬电

5. 优化大功率发热元器件安装位置，分散热源；
6. 恢复柜门，上电运行监测柜内温度曲线；
7. 设定高温预警温度，纳入日常巡检。

1. 严禁长期敞开控制柜柜门强制散热，粉尘会带来短路隐患；
2. 高温柜体检修防止烫伤；
3. 不要短接过热保护强行运行。

### 1.设备简介
继电器依靠电磁线圈通电产生磁力吸合动触点，实现控制回路通断切换；接触器属于大功率继电器，用来控制电机主回路。线圈长期过压、过热、持续通电会造成漆包线绝缘击穿烧毁，直接丧失动作能力。

1. 切断控制回路电源，上锁挂牌；
2. 确认前端控制信号输出正常，判定线圈本体损坏；
3. 更换**同型号、同额定电压**全新继电器；
4. 清理底座内部粉尘、凝露水渍；
5. 手动测试铁芯运动无卡滞，再装入底座；
6. 上电反复测试吸合、断开动作，验证功能稳定。
### 7.安全规范
1. 禁止使用电压规格不符的继电器临时替代；
2. 线圈短路故障排查前不要反复持续送电，避免烧毁前端PLC输出模块；
3. 更换元器件前确认回路完全断电。
### 8.维修案例（真实现场）
故障：输送设备启动继电器无动作，电机无法启动
现象：PLC输出正常，但中间继电器始终不吸合。测量线圈电阻无穷大，线圈外壳焦黑。

4. 核对负载电流，必要时升级更大容量继电器；
5. 清理底座粉尘，检查触点弹簧弹力；
6. 上电多次通断测试，监测触点导通稳定性。

2. 打磨触点仅作为临时抢修方案，条件允许直接更换；
3. 感性负载回路建议增加浪涌吸收元件抑制电弧。

4. 选用额定电流留有充足余量的继电器；
5. 更换新继电器后，空载、带载多次启停测试。

1. 触点粘连属于高危故障，极易引发设备误动作、人身伤害；
2. 绝对禁止撬开粘连触点继续投入使用；

正常继电器通电后铁芯稳定吸合；当电磁吸力不足、铁芯端面有杂质，动铁芯会持续高频震动，产生嗡嗡异响。长期抖动会快速磨损触点，加速元器件损坏。
### 2.主要结构：线圈、动静铁芯、短路环（交流接触器）、复位弹簧。
### 3.常见故障
继电器吸合抖动、异响
### 4.故障原因
1. 线圈供电电压偏低，电磁吸力不足以稳定吸合铁芯；
2. 动静铁芯接触面附着粉尘、油污，贴合不紧密；
3. 交流接触器铁芯短路环断裂，交变磁力周期性变化；
4. 复位弹簧预紧力过大，抵消电磁吸力；
5. 线圈供电波形畸变，电压波动剧烈。
### 5.诊断方法
1. 继电器通电持续“嗡嗡”震动异响，触点频繁通断；
2. 测量线圈工作电压低于额定值；
3. 拆开清理铁芯表面后，异响短暂减轻；
4. 交流接触器重点检查铁芯边缘短路环。
### 6.维修流程
1. 断电取下继电器，清理动静铁芯接触面粉尘油污；
2. 测量控制回路电压，排查线路压降大的问题；
3. 短路环断裂的交流接触器直接更换；
4. 检查复位弹簧，更换弹力异常弹簧；
5. 上电测试，确认铁芯平稳吸合无抖动。
### 7.安全规范
1. 持续抖动会快速烧蚀触点，发现异响及时停机处理；
2. 不要短接保护装置强行长期运行。
### 8.维修案例（真实现场）
故障：风机交流接触器通电持续嗡嗡抖动异响
现象：接触器吸合不稳固，负载电流波动。拆解发现铁芯短路环断裂，铁芯表面堆积油污。
根因：长期柜内粉尘积累，加上短路环金属疲劳断裂。
处置：直接更换全新交流接触器；定期清理柜内元器件粉尘。异响彻底消除。
### 9.关键词
接触器抖动、铁芯短路环、电压偏低、电磁吸力不足、铁芯油污


五、变频器类部件故障
# #变频器过流报警（OC）
## 归属部件：变频器
### 1.设备简介
变频器通过调制输出交流电频率调节电机转速；过流保护是核心保护功能，当输出电流超出阈值立刻停机报警，防止功率模块击穿。故障分为启动过流、运行过程过流两大类。
### 2.主要结构
整流模块、IGBT功率模块、驱动板、电流互感器、散热风道。
### 3.常见故障
变频器过流报警（OC）
### 4.故障原因
1. 电机电缆相间/对地短路；
2. 电机绕组匝间短路；
3. 启动参数设置不当：加速时间过短、启动电压过高；
4. 机械负载卡死，电机堵转；
5. 变频器内部IGBT功率模块老化击穿。
### 5.诊断方法
1. 区分报警时机：启动瞬间过流、还是运行一段时间后过流；
2. 断开变频器输出电机电缆，空载启动变频器，判断故障在电机侧还是变频器本体；
3. 兆欧表测量电机、电缆绝缘，排查短路；
4. 核对加减速时间、电机额定参数设置是否匹配；
5. 手动盘车检查机械设备有无卡滞。
### 6.维修流程
1. 停机断电，等待变频器直流电容充分放电，上锁挂牌；
2. 断开输出动力电缆，空载测试变频器；
    - 空载依然过流：变频器内部功率模块故障，送修；
    - 空载正常：故障位于电缆或电机；
3. 排查电机、线缆短路故障，修复受损线路；
4. 优化变频器启动参数，延长加速时间；
5. 解除机械设备卡堵；
6. 全部整改完成，先空载试车，再带载运行。
### 7.安全规范
1. 断电后必须等待电容放电完成才能开盖检修；
2. 频繁过流不要反复多次复位启动，极易击穿功率模块；
3. 禁止随意调高过流保护阈值。
### 8.维修案例（真实现场）
故障：水泵变频器一启动立刻OC过流报警
现象：合闸启动瞬间直接停机报警。断开电机电缆，变频器空载启动正常。
排查：电机动力电缆末端芯线绝缘破损，相间轻微短路。
根因：电缆长期浸泡积水，绝缘层老化破损。
处置：更换故障电缆；复测电机绝缘合格后重新投运。启动不再报过流故障。
### 9.关键词
变频器OC过流、IGBT模块、电机短路、堵转、加速时间、电容放电


##变频器过压报警（OV）
## 归属部件：变频器
### 1.设备简介
变频器直流母线电压存在正常范围；电机快速减速时，惯性机械能回馈至变频器直流母线，造成母线电压飙升，触发过压保护停机。
### 2.主要结构
整流桥、直流母线电容、制动电阻、功率模块。
### 3.常见故障
变频器过压报警（OV）
### 4.故障原因
1. 减速时间设置过短，电机回馈能量无法释放；
2. 大功率惯性负载（风机、水泵）未配置制动电阻；
3. 输入电网电压本身偏高；
4. 制动电阻断线、制动单元失效；
5. 直流母线电容老化，容量下降，稳压能力变差。
### 5.诊断方法
1. 报警多出现在减速停机阶段；匀速运行无报警；
2. 监控变频器直流母线电压数值，减速时电压快速超过阈值；
3. 检查制动电阻接线有无断线，测量电阻阻值；
4. 记录电网输入电压，确认是否长期偏高。
### 6.维修流程
1. 断电等待电容充分放电；
2. 适当延长变频器减速时间，降低回馈能量速率；
3. 惯性负载加装或检修制动电阻、制动单元；
4. 制动电阻断线，重新接线或者更换；
5. 电网长期偏高，联系配电班组调整变压器输出电压；
6. 电容老化严重，安排更换直流母线电容；
7. 修改参数后多次启停测试，观察是否再次报警。
### 7.安全规范
1. 直流母线存在高压，放电不充分禁止触碰内部电路板；
2. 制动电阻工作温度极高，防止烫伤；
3. 禁止取消过压保护强行运行。
### 8.维修案例（真实现场）
故障：引风机变频器减速停机持续报OV过压
现象：风机减速阶段报警停机，匀速运行一切正常。制动电阻接线端子断线，制动回路失效。
根因：风机惯性大，减速回馈能量无法消耗，母线电压持续冲高。
处置：重新接好制动电阻，适度延长减速时间；多次启停测试，过压报警消除。
### 9.关键词
变频器OV过压、直流母线电压、制动电阻、惯性负载、回馈能量、减速时间


##变频器过热保护停机（OH）
## 归属部件：变频器
### 1.设备简介
变频器IGBT功率模块工作产生大量热量，依靠散热风扇、风道散热；模块温度超过设定阈值，触发过热保护停机，防止半导体器件热击穿。
### 2.主要结构
散热风扇、散热翅片、温度检测热敏电阻、风道滤网。
### 3.常见故障
变频器过热保护停机（OH）
### 4.故障原因
1. 散热风扇损坏停转、风扇转速不足；
2. 散热翅片、防尘滤网被粉尘堵塞，气流不畅；
3. 控制柜环境温度过高，散热余量不足；
4. 变频器长期满负荷运行，发热量大；
5. 温度检测热敏电阻老化、信号异常误报警。
### 5.诊断方法
1. 中午高温时段故障高发；停机冷却一段时间后可以短暂运行；
2. 查看变频器内部温度参数，温度持续上升触发报警；
3. 目视检查散热风扇是否正常旋转、滤网积灰情况；
4. 清理风道后，故障明显缓解，确认散热不良。
### 6.维修流程
1. 停机断电，等待设备充分降温；
2. 吹扫清理散热翅片、滤网堆积粉尘；
3. 风扇损坏直接更换同型号散热风扇；
4. 改善控制柜通风条件，避免阳光直晒；
5. 热敏电阻故障，更换温度检测元件；
6. 上电持续监测模块温度，确认温升正常。
### 7.安全规范
1. 高温检修防止烫伤，等待充分降温再开盖；
2. 严禁短接过热保护强制运行，极易烧毁功率模块；
3. 吹扫粉尘务必断电操作。
### 8.维修案例（真实现场）
故障：供水泵变频器午后频繁OH过热报警
现象：上午运行正常，环境气温升高后报警停机。检查散热滤网完全被灰尘封堵，风扇运转缓慢。
根因：长期未清理风道，风量不足，热量堆积。
处置：彻底吹扫散热翅片，更换散热风扇，定期月度清理滤网。设备不再触发过热保护。
### 9.关键词
变频器OH过热、散热风扇、风道堵塞、功率模块、热敏电阻、环境温升


# #变频器输出缺相、电机三相电流不平衡
## 归属部件：变频器
### 1.设备简介
变频器输出三相PWM驱动电机；输出回路一相断路、功率模块单边损坏时，供给电机的三相电压不平衡，造成电机电流失衡、异响、发热。
### 2.主要结构
三相IGBT功率模块、输出电流互感器、动力输出端子。
### 3.常见故障
变频器输出缺相、电机三相电流不平衡
### 4.故障原因
1. 变频器输出端子接线松动、烧蚀，单相断路；
2. 一相IGBT功率模块损坏，无输出；
3. 电机动力电缆单芯断裂；
4. 电流互感器故障，检测异常；
5. 电机内部绕组故障。
### 5.诊断方法
1. 电机运行出现低频嗡嗡异响，机身温升加快；
2. 钳形表测量三相输出电流，三相数值偏差巨大；
3. 断开电机电缆，空载测量变频器三相输出电压；
4. 区分故障属于变频器本体，还是外部电缆、电机。
### 6.维修流程
1. 断电、等待电容放电，上锁挂牌；
2. 紧固变频器输出动力端子，清理氧化烧蚀痕迹；
3. 空载测试三相输出电压不平衡：判定变频器功率模块损坏，送维修；
4. 空载输出平衡：排查后端电缆与电机故障；
5. 全部修复完成，空载试运行，监测三相电流均衡性；
6. 带载持续运行复测温升与电流。
### 7.安全规范
1. 电机电流不平衡不可长期运行，极易烧毁绕组；
2. 变频器内部高压，无维修资质不要自行拆装功率板；
3. 反复启停前确认故障根源。
### 8.维修案例（真实现场）
故障：搅拌电机三相电流偏差达到22%，电机异响发热
现象：变频器运行无报警，但电机温升超标。断开电机电缆，变频器空载三相输出电压不平衡。
根因：变频器一相IGBT模块性能衰减，输出幅值不足。
处置：变频器送专业维修更换功率模块；修复后三相电流差值控制在8%以内。
### 9.关键词
输出缺相、IGBT模块损坏、三相电流不平衡、PWM输出、电机异响发热


# #变频器通讯故障，无法与PLC交互
## 归属部件：变频器
### 1.设备简介
变频器依靠RS485/Modbus通讯线缆与PLC传输启停指令、频率、故障代码。通讯链路中断会造成PLC无法控制变频器，无法读取运行参数。
### 2.主要结构
通讯板、485通讯端子、屏蔽通讯线缆、终端电阻。
### 3.常见故障
变频器通讯故障，无法与PLC交互
### 4.故障原因
1. 通讯线缆破损、端子松动；
2. 通讯地址、波特率、校验位参数与PLC不匹配；
3. 总线缺少终端电阻，信号反射造成通讯不稳定；
4. 屏蔽线缆接地方式错误，电磁干扰干扰通讯；
5. 变频器通讯板硬件损坏。
### 5.诊断方法
1. PLC频繁报通讯超时，变频器时而在线时而离线；
2. 核对两端通讯参数（波特率、站地址、协议）；
3. 使用通讯检测工具监视总线信号；
4. 短距离临时更换通讯线，判断线缆是否故障。
### 6.维修流程
1. 停机后断电，检查通讯端子紧固状态；
2. 统一核对PLC与变频器通讯协议、波特率、站号；
3. 总线首尾两端加装120Ω终端匹配电阻；
4. 整改屏蔽电缆，执行单端接地，远离动力电缆；
5. 线缆完好依旧通讯失败，更换变频器通讯板；
6. 上电持续监控通讯在线状态。
### 7.安全规范
1. 通讯失控会造成远程无法停机，涉及联锁工艺优先就地控制；
2. 通讯线禁止和大功率动力电缆同桥架近距离敷设；
3. 修改通讯参数做好记录，防止参数冲突。
### 8.维修案例（真实现场）
故障：PLC周期性丢失变频器通讯，远程无法调速
现象：通讯断断续续。排查发现总线两端未加装终端电阻，控制线与动力电缆并行敷设干扰信号。
根因：信号反射叠加电磁干扰，Modbus通讯数据包频繁出错。
处置：增加120Ω终端电阻，重新整理线缆桥架，强弱电分离。通讯掉线现象彻底消除。
### 9.关键词
Modbus通讯、通讯超时、终端电阻、485总线、电磁干扰、通讯板故障
